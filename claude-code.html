เริ่มใช้ Claude Code ยังไง

  1. มีบัญชี Claude แบบเสียเงิน หรือ APIดูแพ็กเกจที่ claude.com/pricing
  2. เลือกช่องทางที่ถนัดไม่ชอบหน้าจอดำ ใช้ส่วนเสริมใน VS Code หรือแอป Desktop ได้ · วิธีติดตั้งล่าสุดดูที่คู่มือทางการ docs.claude.com
  3. เปิดในโฟลเดอร์งานให้มันเห็นไฟล์ที่จะทำ เช่น โฟลเดอร์คลิป หรือโฟลเดอร์เว็บ
  4. พิมพ์สั่งเป็นภาษาไทยบอกผลที่อยากได้ ไม่ต้องบอกวิธี เช่น "ย่อวิดีโอนี้ให้ต่ำกว่า 20 MB"
  5. อ่านก่อนกดอนุญาตมันจะบอกว่ากำลังจะแก้ไฟล์ไหน รันคำสั่งอะไร — ไม่แน่ใจ ถามมันก่อนได้
  6. เขียนกฎไว้ใน CLAUDE.mdสิ่งที่ต้องย้ำทุกครั้ง เขียนไว้ในไฟล์ ครั้งหน้ามันอ่านเอง

ข้อควรระวัง (เจอเองมาแล้ว)

มันแก้ไฟล์จริง — สำรองไฟล์ก่อนเสมอ หรือใช้ git จะย้อนกลับได้ทุกขั้น · งานที่ส่งออกข้างนอก (push ขึ้นเว็บ · ใช้เครดิต) ให้มันถามก่อนทุกครั้ง
ระวังข้อมูลลับ — ตอนหา API key ในเครื่อง มันเคยพิมพ์รหัสออกมาให้เห็นใน log · บอกไว้ใน CLAUDE.md ว่าห้ามแสดงรหัส และเก็บ key ไว้ในที่ที่ควรเก็บ
ตรวจงานที่มองไม่เห็น — มันเช็คตัวเลข ไฟล์ ลิงก์ได้ แต่บางงาน (หน้าตาคลิป · สำเนียงพูด) คนต้องดูเอง
สั่งเป็นผลลัพธ์ ไม่ใช่วิธี — "อยากได้ซับไทยตัวหนา ภาษาอังกฤษไม่กระโดด" ได้ผลดีกว่าบอกขั้นตอนเอง

Claude Code ต่างจาก Claude หรือ ChatGPT ในหน้าแชตยังไง

ในหน้าแชต AI ตอบเป็นข้อความ เราต้องก๊อปไปทำต่อเอง ส่วน Claude Code ลงมือทำในเครื่องให้เลย เปิดไฟล์ แก้ไฟล์ รันโปรแกรม แล้วรายงานผล โดยขออนุญาตก่อนทุกครั้งที่จะแก้ไฟล์หรือรันคำสั่ง

ใช้ Claude Code ต้องเขียนโค้ดเป็นไหม

ไม่ต้อง พิมพ์สั่งเป็นภาษาไทยธรรมดาได้เลย เช่น "ใส่ซับให้คลิปนี้" หรือ "ย่อวิดีโอให้เล็กลง" แต่ควรอ่านสิ่งที่มันจะทำก่อนกดอนุญาต และควรมีสำเนาไฟล์สำรองไว้เสมอ

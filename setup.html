ติดตั้งเครื่องก่อนเรียน คำสั่งเดียวจบ

คัดลอกคำสั่ง 1 บรรทัด วางแล้วกด Enter เครื่องจะติดตั้งทุกอย่างของคอร์สให้เอง พร้อมตั้งค่า PATH ให้ใช้ได้ทันที ทำที่บ้านก่อนวันเรียน ใช้เวลาประมาณ 10–30 นาที

Macเครื่องของคุณ

  1. เปิด Terminalกด Cmd + Space พิมพ์ Terminal แล้วกด Enter
  2. กด Copy แล้ววางใน Terminal กด Enter 
    curl -fsSL https://nerdmartech.com/setup/mac.sh | bash
  3. ใส่รหัสผ่านเครื่อง 1 ครั้งรหัสเดียวกับที่ใช้ปลดล็อกเครื่อง ตอนพิมพ์จะไม่เห็นตัวอักษร เป็นเรื่องปกติ พิมพ์ให้ครบแล้วกด Enter
  4. รอจนขึ้น ✅ ครบทุกข้อแคปหน้าจอส่งในกลุ่ม LINE

Windowsเครื่องของคุณ

  1. เปิด PowerShellกดปุ่ม Windows พิมพ์ PowerShell แล้วกด Enter (เปิดแบบปกติ ไม่ต้อง Run as administrator)
  2. กด Copy แล้ววางใน PowerShell กด Enter 
    irm https://nerdmartech.com/setup/win.ps1 | iex
  3. มีหน้าต่างถามว่า "อนุญาตให้แอปนี้เปลี่ยนแปลงอุปกรณ์ไหม" กด Yesจะเด้งขึ้นหลายครั้ง เพราะติดตั้งหลายโปรแกรม
  4. รอจนขึ้น ALL DONE สีเขียวแคปหน้าจอส่งในกลุ่ม LINE
หลังติดตั้งเสร็จ ปิด VS Code ให้หมดแล้วเปิดใหม่ (Mac กด Cmd + Q) โปรแกรมที่เปิดค้างไว้ก่อนติดตั้งจะยังหาเครื่องมือใหม่ไม่เจอ

ติดตั้งอะไรบ้าง

โปรแกรมใช้ทำอะไรในคอร์ส
Git · Node.jsให้เว็บและระบบที่เราสร้างรันในเครื่องได้
VS Code + ส่วนขยาย Claude Codeที่ทำงานหลัก คุยกับ Claude และเห็นไฟล์ทั้งหมด

FFmpegให้ Claude ตัดต่อวิดีโอ
Class Kitคำสั่ง /memo · /todo ที่ใช้ทั้งคอร์ส
MCP Vercel · Supabase · Meta adsให้ Claude เข้าไปทำงานในระบบเหล่านี้แทนเรา (ล็อกอินในห้องเรียน)

ตัวไหนมีอยู่แล้ว สคริปต์จะข้ามให้ รันซ้ำกี่รอบก็ได้

ติดปัญหา

  1. ขึ้น ❌ หรือ [X] บางข้อปิดหน้าต่างแล้วเปิดใหม่ วางคำสั่งเดิมอีกรอบ ตัวที่ลงแล้วจะข้ามให้
  2. ยังไม่ผ่านส่งแคปหน้าจอ + ไฟล์ nerdmartech-setup.log (อยู่ในโฟลเดอร์ผู้ใช้ของเครื่อง) ในกลุ่ม LINE
  3. Mac บอกว่ารหัสผ่านไม่ถูกบัญชีที่ใช้อาจไม่ใช่ผู้ดูแลเครื่อง (เครื่องบริษัท) ให้ฝ่าย IT ช่วย หรือใช้เครื่องส่วนตัว
  4. Windows บอกว่าไม่มี wingetสคริปต์จะเปิด Microsoft Store ให้ กด Update/Install "App Installer" แล้วรันคำสั่งอีกรอบ
